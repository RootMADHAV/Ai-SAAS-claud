## What this is

An AI-assisted platform for discovering, analyzing, prioritizing, and
reporting security vulnerabilities -- scanner orchestration (Nuclei,
Nmap, ffuf, and others), AI-driven analysis and enrichment (CVE/CWE
mapping, severity and exploitability assessment, remediation guidance),
and professional report generation.
